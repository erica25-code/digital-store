# Digital Store

Projeto final de Front-end (React + Vite).

## Equipe
- Maria Erica Alves de Oliveira

## Como rodar
1. Clone o repositório
2. `npm install`
3. `npm run dev`

## Páginas
- Home (/)
- Listagem de produtos (/products)
- Visualização do produto (/product/:id)

## Tecnologias
React, React Router DOM, Vite, CSS
